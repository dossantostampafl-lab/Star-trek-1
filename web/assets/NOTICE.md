# Créditos da arte

Os personagens (`crew/`) e os móveis (`furniture/`) vêm do projeto **StarNet**
(https://github.com/androoAGI/starnet), de Andrew Sims, distribuído sob a licença MIT.
Os personagens foram recortados e reunidos em folhas de sprites (uma por personagem);
os móveis estão como no original.

Só foram trazidos desenhos genéricos — nenhum personagem de filme, jogo ou pessoa real.

## Sprite sheet (`crew/<personagem>.png`)

Quadros de 64×96 px, 8 colunas:

| linha | conteúdo |
|---|---|
| 0 | parado: sul, leste, oeste, norte · sentado: sul, leste, oeste, norte |
| 1 | andando para leste (8 quadros) |
| 2 | andando para oeste |
| 3 | andando para sul |
| 4 | andando para norte |
| 5 | digitando de costas (4 quadros) |
