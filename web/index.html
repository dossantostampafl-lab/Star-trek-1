✈️ Telegram

  1. No Telegram, abra @BotFather e mande /newbot. Escolha um nome e um usuário terminado em bot.
  2. Copie o token que ele mostrar e cole aqui.
  3. Toque em Gerar código e mande o código para o seu bot.

🎮 Discord

  1. Em discord.com/developers/applications: New Application → aba Bot → Reset Token e copie.
  2. Na mesma aba, ligue Message Content Intent.
  3. Cole o token aqui e toque em Salvar e conectar. Depois use o link Convidar para pôr o bot num servidor seu.
  4. Mande uma mensagem direta para o bot com o código de pareamento.
