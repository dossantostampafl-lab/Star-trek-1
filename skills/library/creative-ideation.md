Any open-ended generative ask — "help me make/build/write something", "I'm stuck", "inspire me", "make this weirder", "help me pick" — deserves method, not slop. Read the situation, pick ONE matching method, apply it, produce ideas that are specific and non-obvious.

## Operating rules
1. **Constraint + direction = creativity.** No constraint, no traction; no direction, no shape. A method supplies both.
2. **Refuse the first three ideas.** They're the obvious ones everyone reaches. Generate, discard, regenerate.
3. **One method per response** unless they ask for more. Don't stack.
4. **Specificity over abstraction.** Real mechanisms, real materials, real proper nouns. "An app for X" is slop; "a 200-line tool that prints Y when Z" is direction. Naming a tech stack is not specificity — name a *mechanism*.
5. **Weird must also be good.** Frame-breaking is the goal, but always include at least one idea that is genuinely buildable now — non-obvious yet grounded, with a real first step.
6. **Name the method and who invented it.** Attribution invokes the discipline.
7. **When they pick one, build it.** Stop generating.

## Routing — read the phase, then pick a method
- **Generating** (no idea yet) → *constraint dispatch*: impose a random hard constraint (a budget, a material, a deadline, a forbidden word) and design within it.
- **Expanding** (has a base idea) → *SCAMPER* (substitute, combine, adapt, modify, put-to-other-use, eliminate, reverse) — run it on the base.
- **Selecting** (has options) → score each against their real priorities; name the one that wins and the tradeoff it costs.
- **Unblocked** (stuck / going in circles) → *invert the goal* (how would I guarantee the OPPOSITE outcome?) then negate each answer.
- **Subverting** ("too safe", "make it weirder") → *lateral provocation*: state a deliberately absurd premise, then mine it for the one usable idea hiding inside.
- **Synthesizing** (a pile of notes) → cluster into 3-5 themes, name the tension between them, propose what resolves it.

For high-slop terrain (AI ideas, startup ideas, habit trackers, productivity apps) refuse the first FIVE ideas and force a provocation method.

*Pure reasoning — needs no workstation objects.*
